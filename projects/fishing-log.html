釣果記録アプリ FishingLog

  • 個人開発
  • 公開中

開発期間

約3週間（2026年9月25日〜10月16日）

概要

釣りに行く前に開く、釣果記録・釣り場情報共有アプリです。日付を選ぶと、その日の潮と、同じ時期の自分やほかの釣り人の記録から「行くならどの釣り場か」を提案します。釣ったあとに投稿するアプリではなく、「次の休日にどこへ行って、どう釣れば釣れるか」を記録から決めるための道具として設計しました。

釣り人が記録を公開しない一番の理由は「ポイントを知られたくない」ことなので、全体公開／釣り場だけ隠す／非公開の3段階の公開範囲を用意し、隠す情報は画面ではなくサーバー側で取り除くなど、場所を守る仕組みに力を入れました。

主な機能

  • 釣行プランナー（行く日の潮を計算し、同じ時期・時間帯・潮の記録から釣り場を順に並べる。一致した条件をハンコで表示）
  • 釣り場カルテ（その日の潮・天気予報・次の大潮、「何回行って何回釣れたか」、月×魚種の表、現地の情報）
  • 釣行の記録（写真から撮影日時と近くの釣り場の候補を出す。潮と天候は自動入力。昔の釣行のまとめて登録）
  • 公開範囲3段階（釣り場だけ隠す・位置は約1km四方にぼかす・写真の位置情報(Exif)を保存時に削除）
  • ダッシュボード（累計の指標・連続記録のスタンプ・気づきカード）とシーズンヒートマップ
  • 釣行の条件検索とCSV出力（自分のデータだけ）
  • 釣果フィード（ログインしなくても見られる）・県内新着のお知らせ
  • 不適切な投稿の報告と管理画面
  • 単位変換（重さ・長さ・ラインの号/lb/kg）

使用技術

  • PHP 8.5
  • Laravel 13（Breeze・Blade）

  • Alpine.js / Tailwind CSS v3 / Vite

  • MET Norway・Open-Meteo（天気）
  • Docker / Laravel Sail
  • Render・Aiven・Cloudflare R2（公開）、GitHub Actions
  • PHPUnit（Featureテスト322件）
