weather-app

  • 個人開発 (private)

開発期間/作業時間

約２０時間

概要

ユーザーの現在地や、保存したお気に入り地域の天気を手軽に確認できる、お天気アプリケーションのフロントエンド画面です。バックエンドのLaravel APIと連携し、外部の気象APIからデータを取得してリアルタイムに描画します。

主な機能

  • 現在位置のGPS取得(Geolocation API連携)
  • 逆ジオコーディングによる地名特定(国土地理院API連携)
  • リアルタイム天気情報の表示(Open-Meteo API連携)
  • お気に入り・履歴地域のセレクトボックス表示
  • 重複登録防止の通信スキップ制御機能
  • Tailwind CSSによるレスポンシブデザイン

使用技術

  • JavaScript(Vanilla ES6+)
  • Tailwind CSS(Standalone CLI)
  • Docker
  • Node.js 24.15.0 / npm 11.12.1
  • Vitest / JSDOM(単体テスト・統合テストを実装)
  • Open-Meteo API(気象データ取得)
  • 国土地理院API(逆ジオコーディング)
