attendance-managemet

  • 個人開発 (private)

開発期間/作業時間

約50時間

概要

勤怠管理アプリです。Laravel・Docker・MySQLを用いたフルスタックのWebアプリケーションで、利用者は打刻や勤務履歴の確認、修正申請ができ、管理者はスタッフの勤怠状況の確認やCSV出力、申請承認などを行えます。

主な機能

利用者向け機能

  • ユーザー認証(新規登録・ログイン・メール認証)
  • 打刻機能(出勤・退勤・休憩開始・休憩終了をリアルタイムに記録)
  • 勤務履歴閲覧(過去の勤務データ・休憩時間・実働時間を一覧表示)
  • 修正申請(勤務データの修正依頼、管理者への承認申請)

管理者向け機能

  • スタッフ管理(登録済みスタッフの一覧表示)
  • 日別勤怠確認(特定日の全スタッフの勤怠状況を一覧表示)
  • スタッフ別勤怠閲覧(個別スタッフの月次勤怠データを一覧表示)
  • CSV出力(スタッフの月次勤怠データをダウンロード)
  • 申請承認(スタッフからの修正依頼を承認)

使用技術

  • PHP 8.x
  • Laravel 10.x
  • MySQL 8.0.26
  • Docker / Docker Compose
  • Nginx 1.21.1
  • PHPUnit(34項目のテストを実装し全て通過)
  • MailHog(メール送受信のテスト環境)
